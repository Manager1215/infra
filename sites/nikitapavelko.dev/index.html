Kiln

Open source, 2026source

What it is

Runs Java Fabric mods, unmodified, inside Horizon, the Rust rewrite of Minecraft 26.3. Nothing gets decompiled or patched: the jar runs as it is, and its calls into Minecraft and the Fabric API become calls into Horizon. About 65k lines of Rust and Java.

  • Java runs as its own process next to the game, since Horizon doesn't allow unsafe code inside it.
  • Each mod gets a client tick 20 times a second with the game state, key presses and advancements. What it draws goes onto the HUD.
  • Coverage is measured, not guessed: a testbench of 139 probes over Minecraft and the Fabric API.

Behind it

  • 557 commits and 127 merged PRs in two weeks. Private dev repo, public release repo, and the publish script stops a release that would leak anything. 120 decisions written down ADR-style.
  • 5 GitHub Actions workflows: daily scan of the mod catalogue, nightly build, manual checks. Mod code from strangers runs in a network namespace with no network.
  • Burned through the free 2,000 Actions minutes. Found the push trigger that ate them and moved CI to self-hosted runners on my own 32-core Arch server.
  • The MacBook stays a work machine. Builds, tests and mod checks run on that server over SSH, and so does mutation testing (cargo-mutants plus custom Java mutants), which is far too heavy for a laptop. check.sh gives each run its own git worktree, writes step markers and picks up after a dropped connection.
  • That server sleeps when idle. Wake-on-LAN to wake it, a polkit rule to suspend it over SSH, a script that won't suspend while cargo, javac or gradle are running. Checked resume with an NVIDIA GPU.
  • Site on an Ubuntu VPS: nginx, Let's Encrypt, a small Python account service under systemd.
